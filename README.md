# Shop Buddy App

Build a single-page e-commerce website called “ShopEasy” with two sections on one page. (1) Storefront: a hero banner, a responsive product grid with image, name, price, stock status and an “Add to cart” button, plus a cart drawer showing items, quantities and total. (2) Inventory management panel (reachable from a top-nav “Admin” tab): a table of products with columns for ID, name, category, price, stock and status, with the ability to add, edit and delete products, and low-stock highlighting (below 5 units). Stock should reduce when items are purchased. Use React with Tailwind, a clean modern design, and seed it with 8 sample products. Keep state in the browser so no backend is needed.
